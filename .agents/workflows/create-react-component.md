# Workflow: Створення нового React компонента

Команда для виклику: `/create-react-component`

Опис: Створює новий компонент у папки проєкту разом із файлом стилів CSS Modules без використання Tailwind.

Кроки виконання:

1. Запитай у користувача назву нового компонента (якщо вона не була передана в команді).
2. Створи компонент у правильній директорії (наприклад, у `src/components/НазваКомпонента/`).
3. Створи два файли:
   - `НазваКомпонента.jsx` (функціональний компонент з базовим шаблоном та імпортом стилів).
   - `НазваКомпонента.module.css` (пустий базовий файл стилів).
4. Переконайся, що імпорт стилів прописаний правильно: `import css from './НазваКомпонента.module.css';`.
5. Покажи користувачу створені файли через звіт та запропонуй додати першу логіку.
