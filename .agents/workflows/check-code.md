# Workflow: Перевірка коду перед комітом

Команда для виклику: `/check-code`

Опис: Запускає перевірки та аналізує поточні зміни в проєкті.

Кроки виконання:

1. Запусти через термінал команду перевірки лінтера `npm run lint`.
2. Проаналізуй вивід термінала на наявність попереджень чи помилок ESLint.
3. Якщо є помилки — запропонуй автоматичні виправлення та покажи їх через інлайн-диф.
4. Переконайся, що в змінених файлах немає залишених тестових шматків коду або незакритих дужок.
