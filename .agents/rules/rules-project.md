## Головне правило проєкту (Single Source of Truth)

- **Мова спілкування:** Усі пояснення, плани реалізації, специфікації та повідомлення комітів пиши виключно **українською мовою**.
- **Конституція проєкту:** Перед будь-яким плануванням, генерацією або рефакторингом коду обов'язково прочитай кореневий файл `AGENTS.md` та суворо дотримуйся всіх його вимог (стек, 3-файлова структура Redux, CSS Modules без Tailwind і Grid, безпечний рендеринг масивів, стандарти REST API).
- **Перевірка якості:** Перед завершенням будь-якого завдання обов'язково виконуй перевірку лінтером (використовуй `/check-code` або `npm run lint`).
